# UI Roadmap — план развития интерфейса

Черновик идей, записан 2026-08-04. Все пункты — **только шаблоны** (`web/templates/*`): без изменений бэкенда и без увеличения нагрузки на LLM (баланс «минимум на входе, точный результат» не трогаем).

## Идеи

### 1. Атмосфера таверны (приоритет: высокий, стоимость: низкая)
Интерфейс выглядит как панель управления, а не как место перед приключением. Grey-900 заменить на тёплую тёмную палитру (stone/amber — как свечной свет), заголовки с засечками (фолиант), тонкие разделители «✦» между секциями. Кнопка «Начать игру» уже янтарная — усилить свечение (костёр).
- Где: lobby.html, backstories.html, backstories_players.html, slots.html
- Как: правки Tailwind-классов, пара CSS-правил

### 2. Шаги путешествия (приоритет: высокий, стоимость: низкая)
Индикатор этапов: Лобби → Предыстории → Мир/Игра, текущий подсвечен. Группа всегда видит, где находится и что дальше.
- Где: общий элемент, дублируется в lobby.html и backstories.html
- Как: 3 строки HTML + CSS

### 3. Честная кнопка «Начать игру» (приоритет: средний, стоимость: копеечная)
Сейчас кнопка серая без объяснений, когда нет персонажей. Подпись под ней: «Добавьте хотя бы одного персонажа, чтобы начать».
- Где: lobby.html

### 4. Подсказки в предысториях (приоритет: средний, стоимость: копеечная)
Плейсхолдер в поле предыстории: «Кто ты? Откуда пришёл? Что тобой движет?» — новичкам проще, мастеру больше материала для вплетения.
- Где: backstories.html / backstories_players.html

### 5. Карточки игроков в лобби (приоритет: низкий, стоимость: средняя)
Слоты сейчас минимальные. Пометить «Вы» у своего браузера, каждому персонажу — маленькая иконка-символ.
- Где: slots.html
- Как: чуть больше работы, но тоже только шаблон

### 6. Первое описание «куда попали игроки» (приоритет: низкий, стоимость: копеечная)
Друзья заходят по ссылке впервые — строка-приглашение в лобби: «Это ваш общий стол: войдите как персонаж, напишите предысторию — и мастер создаст под вас мир».
- Где: lobby.html
- Как: текст, без логики. Утверждено Повелителем 2026-08-04.

## Рассмотрено и отклонено (чтобы не предлагать снова)
- **Детализация ожидания генерации мира** («мастер думает о сеттинге...»): отклонено — обновление страницы ни на что не влияет, фразы «мастер занят» достаточно; подробности — в логах консоли сервера (техническая информация).
- **Сообщение при входе в занятую игру**: уже реализовано — панелька «игра идёт — мест нет, ждите или просите перезапуск» (2026-08-04, не заметил автор предложения в коде).

## Правила
- Любое изменение интерфейса — только в шаблонах, без троек бэкенда и LLM.
- Перед внедрением — подтверждение Повелителя (его тесты не дублировать, UI проверяет сам).
