# AI Tabletop Framework

Веб-фреймворк для проведения настольных ролевых игр (TRPG) в кругу друзей.
Роль Гейм-Мастера выполняет языковая модель — **deepseek-v4-flash-free** через opencode.ai.

## Установка

1. Установите [Poetry](https://python-poetry.org/docs/#installation).
2. Скопируйте проект и установите зависимости:

```bash
cd AITTF
poetry install
```

3. Создайте `AITTF/.env` (скопируйте из `.env.example`):

```env
API_KEY=your_api_key_here
BASE_URL=https://opencode.ai/zen/v1
MODEL=deepseek-v4-flash-free
```

Ключ opencode.ai можно получить в настройках аккаунта на [opencode.ai](https://opencode.ai).
Для смены провайдера укажите `BASE_URL` другого OpenAI-совместимого API и соответствующую модель:
| Провайдер | BASE_URL | MODEL |
|-----------|----------|-------|
| OpenAI | `https://api.openai.com/v1` | `gpt-4o-mini` |
| OpenRouter | `https://openrouter.ai/api/v1` | `cognitivecomputations/dolphin3.0-r1-mistral-24b:free` |
| LM Studio (локально) | `http://localhost:1234/v1` | `*` |

## Запуск

```bash
cd AITTF
poetry run uvicorn web.main:app --host 0.0.0.0 --port 8000
```

## Как играть

### 1. Инициализация мира

Перед первым запуском сервера создайте мир:

```bash
cd AITTF
poetry run python init_game.py
```

Скрипт попросит ввести имена персонажей (1–5), сгенерирует через ИИ сеттинг, глобальный конфликт и характеристики, сохранит всё в SQLite.

### 2. Выбор персонажа

- Откройте `http://localhost:8000` — попадёте на страницу выбора персонажа.
- Для доступа с других устройств в локальной сети узнайте IP сервера (например, `ipconfig` или `ip a`) и откройте `http://<IP>:8000` — сервер запускается на `0.0.0.0`, фаерволл должен разрешать входящие на порт 8000.
- Выберите свободного персонажа — установится cookie `player_id`.
- После выбора откроется игровой чат.
- `/logout` — сброс выбора, возврат на страницу выбора.

### 3. Игровой процесс

- **Чат** — поле «Сказать» для реплик персонажа (отправляется AI как речь).
- **Действия** — кнопка «Заявить действие» для официальных ходов (осмотр, атака, переговоры).
- **Таймер** — 15 секунд бездействия после последнего сообщения; по истечении AI-Мастер автоматически двигает сюжет.
- **Блокировка формы** — пока AI генерирует ответ, ввод и кнопки блокируются, индикатор «Мастер думает...» пульсирует.
- **Обновления в реальном времени** — WebSocket `/ws/chat` доставляет сообщения, статусы, панель игроков и таймер всем без перезагрузки.
- **HP и панель игроков** — обновляются автоматически в боковой панели.

### 4. Админ-панель

Доступна по `/admin`:
- Редактирование текущих и максимальных HP игроков.
- Переключение статуса игры (exploration / combat).

## Особенности интерфейса

- **Автоскролл чата** — при отправке сообщения чат скроллится вниз принудительно; при получении новых сообщений скроллится только если пользователь не листал вверх (иначе появляется кнопка `↓`).
- **Пульсирующая кнопка вниз** — если пришли новые сообщения, а пользователь отмотал вверх.
- **Очистка поля ввода** — после отправки сообщение из поля удаляется.
- **HTMX-полинг** — `/chat_fragment` и `/players_panel` обновляются каждые 3с / 5с.
- **Таймер** — поллинг `/timer` каждую секунду, OOB-замена плашки «Мастер внимательно слушает...».

### Технологии

| Компонент | Что используется |
|-----------|-----------------|
| Сервер | FastAPI + Uvicorn |
| Фронтенд | HTMX 2.x + Tailwind CSS (CDN) |
| База данных | SQLite (через sqlite3) |
| Схемы | Pydantic v2 |
| HTTP-клиент | httpx (для вызова LLM) |
| WebSocket | `websockets` (библиотека Python) + встроенный WebSocket API |
| Модель | deepseek-v4-flash-free через opencode.ai |
