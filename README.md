# AI Tabletop Framework

Веб-фреймворк для проведения настольных ролевых игр (TRPG) в кругу друзей.
Роль Гейм-Мастера выполняет языковая модель через OpenAI-совместимый API.

## Установка

1. Установите [Poetry](https://python-poetry.org/docs/#installation).
2. Скопируйте проект и установите зависимости:

```bash
cd AITTF
poetry install
```

3. Создайте `AITTF/.env` (скопируйте из `.env.example`):

```env
API_KEY=your_api_key_here
BASE_URL=https://opencode.ai/zen/v1
MODEL=deepseek-v4-flash-free
```

Для смены провайдера укажите `BASE_URL` другого OpenAI-совместимого API:
| Провайдер | BASE_URL | MODEL |
|-----------|----------|-------|
| opencode.ai | `https://opencode.ai/zen/v1` | `deepseek-v4-flash-free` |
| OpenAI | `https://api.openai.com/v1` | `gpt-4o-mini` |
| OpenRouter | `https://openrouter.ai/api/v1` | `cognitivecomputations/dolphin3.0-r1-mistral-24b:free` |
| LM Studio (локально) | `http://localhost:1234/v1` | `*` |

## Запуск

```bash
cd AITTF
poetry run uvicorn web.main:app --host 0.0.0.0 --port 8000
```

Для доступа с других устройств в локальной сети узнайте IP сервера (`ipconfig` / `ip a`) и откройте `http://<IP>:8000`. Фаерволл должен разрешать порт 8000.

## Как играть

### 1. Лобби

Откройте `http://localhost:8000` — попадёте в лобби.
- Введите имя персонажа и нажмите **Войти** — вы попадёте в игру под этим именем.
- После входа появится блок «это вы» с возможностью **сменить имя** или **выйти**.
- Можно добавить любое количество игроков (каждый со своего браузера).
- Кнопка **Начать игру** становится активна, когда в лобби есть хотя бы один персонаж. Видна только тем, кто уже вошёл.
- Если игра уже началась, лобби показывает сообщение «Игра уже началась» — присоединиться нельзя.
- Уже созданные персонажи можно занять через страницу `/choice` (выбор свободного персонажа и вход за него).
- Изменения в лобби (вход, выход, переименование) сразу видны всем игрокам без перезагрузки страницы.

### 2. Предыстории

После перехода в режим сбора предысторий каждый игрок заполняет свою предысторию в текстовом поле и нажимает **Закрепить**. После этого поле блокируется — изменить предысторию больше нельзя. Когда все предыстории готовы, становится доступна кнопка **Сгенерировать мир**. Статус заполнения предысторий других игроков обновляется в реальном времени.

### 3. Генерация мира

LLM анализирует концепты и предыстории всех персонажей и генерирует:

- **Сеттинг** — название и описание мира
- **Глобальный конфликт** — завязка сюжета и общая цель для группы
- **Персональные характеристики** — 2–4 уникальных стата на каждого персонажа. Каждый стат имеет тип (боевой / защитный / прочий), описание и начальное значение (1–10). Защитные статы определяют максимальное HP
- **Классы/архетипы** — уникальная роль и её описание для каждого персонажа
- **Вступительный текст** — атмосферная сцена, погружающая в мир

Во время генерации интерфейс показывает статус «Мастер создаёт мир...». Результат выводится в игровой чат тремя сообщениями: сеттинг, суть конфликта и вступительный текст.

### 4. Игровой процесс

- **Чат и действия** — единое поле ввода. Кнопка «Сказать» отправляет реплику, «Заявить действие» — то же самое, но сообщение визуально выделяется в чате как действие персонажа.
- **Таймер** — 15-секундное окно после каждого сообщения или действия, в течение которого игроки могут дописать свои фразы, не вызывая LLM на каждое слово. При истечении накопленные сообщения отправляются на обработку.
- **Пауза таймера** — таймер можно поставить на паузу (кнопка ⏸) и позже продолжить.
- **Блокировка формы** — на время генерации ответа AI ввод и кнопки блокируются.
- **Боковая панель** — слева отображаются карточки персонажей: имя, класс, HP-бар, значения характеристик, инвентарь и статус-эффекты. По клику на карточку открывается модалка с полным описанием персонажа.
- **Карточка «Лор/Сюжет»** — внизу боковой панели. По клику открывает описание сеттинга и суть глобального конфликта.
- **Статус игры** — в шапке интерфейса отображается текущий режим (exploration / combat).
- В шапке интерфейса есть ссылки **Сменить персонажа** (выход из текущего) и **Admin** (панель управления). После выхода открывается страница выбора свободного персонажа (если игра уже идёт) или возврат в лобби.

### 5. Админ-панель

`/admin` (доступна только с localhost) — редактирование HP игроков (текущее и максимальное), переключение статуса игры (exploration / combat), сброс партии. Изменения сразу отображаются у всех игроков.

### 6. Сброс игры

Кнопка **Сбросить партию** в лобби, на странице предысторий, в админ-панели и на странице выбора персонажа — очищает БД и возвращает всех игроков в лобби. Требует подтверждения перед выполнением.

## Особенности интерфейса

- **Автоскролл чата** — при отправке принудительный скролл вниз; при получении — только если вы не листали вверх.
- **Кнопка** `↓` — показывается, если вы отмотали вверх; становится красной с пульсацией, если пришли новые сообщения.

## Структура проекта

```
AITTF/
├── __init__.py
├── .env.example          # Шаблон переменных окружения
├── .gitignore
├── init_game.py          # Консольная инициализация (резервная)
├── test_llm.py           # Тест вызова LLM
├── pyproject.toml        # Зависимости (FastAPI, uvicorn, httpx, jinja2, ...)
├── db/
│   ├── __init__.py
│   └── database.py       # SQLite — инициализация, CRUD, таймеры
├── models/
│   ├── __init__.py
│   └── models.py         # Pydantic-схемы
├── llm/
│   ├── __init__.py
│   ├── ai_generator.py   # HTTP-вызов LLM (httpx)
│   ├── context_builder.py# Сборка системного промпта
│   └── turn_processor.py # Парсинг ответа AI, TurnResponse
├── core/
│   ├── __init__.py
│   ├── game_engine.py    # Броски кубиков, инициатива, бой
│   └── initialization.py # Создание игровой сессии
└── web/
    ├── __init__.py
    ├── main.py           # FastAPI-сервер, WebSocket, HTMX-эндпоинты
    └── templates/
        ├── lobby.html               # Лобби (вход, старт игры)
        ├── slots.html               # Сетка слотов игроков
        ├── backstories.html         # Страница предысторий
        └── backstories_players.html # Карточки предысторий игроков
```

### Технологии

| Компонент | Что используется |
|-----------|-----------------|
| Сервер | FastAPI + Uvicorn |
| Фронтенд | HTMX 2.x + Tailwind CSS (CDN) |
| Шаблоны | Jinja2 |
| База данных | SQLite |
| Схемы | Pydantic v2 |
| HTTP-клиент | httpx |
| WebSocket | `websockets` (Python) + WebSocket API |
| Модель | deepseek-v4-flash-free через opencode.ai |
